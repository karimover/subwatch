# Скриншоты для README

После первого локального запуска или деплоя сохраните сюда 2–3 настоящих скриншота приложения:

1. `dashboard.png` — панель управления с месячным эквивалентом и ближайшими списаниями.
2. `subscriptions.png` — список подписок с категориями, датами и статусами.
3. `analytics.png` — графики платежей по месяцам и категориям.

Не заменяйте реальные скриншоты мокапами: материалы должны отражать работающий интерфейс текущей версии.
