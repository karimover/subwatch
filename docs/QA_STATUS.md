# Статус технической проверки

Проверки, выполненные в среде подготовки проекта:

- синтаксический разбор 44 Python-файлов — успешно;
- `compileall` — успешно;
- проверка JavaScript через `node --check` — успешно;
- разбор 12 HTML-шаблонов — успешно;
- разбор CSS через `tinycss2` — ошибок не найдено;
- проверка импортов простым AST-анализом — неиспользуемых импортов не обнаружено;
- в проекте присутствуют 22 Django-теста.

**Ограничение среды:** здесь отсутствует Django, а установка зависимостей из PyPI недоступна из-за сетевого ограничения. Поэтому `python manage.py check`, `makemigrations --check` и `python manage.py test` в этой среде не выполнялись. Не считать тесты пройденными до запуска CI или локального прогона.

После публикации репозитория GitHub Actions установит зависимости и автоматически выполнит Ruff, системную проверку Django, проверку состояния миграций и тесты на Python 3.12 и 3.13. При первом запуске CI необходимо устранить все найденные замечания до сдачи проекта.
